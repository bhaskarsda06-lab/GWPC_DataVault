# Compliance Evidence Checklist

## Deployment
- [ ] Approved change reference
- [ ] Git commit recorded
- [ ] Production deployment timestamp recorded
- [ ] Deployment result recorded

## Validation
- [ ] Build result retained
- [ ] Smoke-test result retained
- [ ] Operational-test result retained
- [ ] Alerting/recovery validation retained
- [ ] Security/governance validation retained
- [ ] Audit/lineage validation retained

## Security
- [ ] Approved identity recorded
- [ ] Access review evidence retained
- [ ] Secret-management control confirmed
- [ ] No credentials included in evidence

## Lineage
- [ ] Source-to-staging lineage documented
- [ ] Staging-to-vault lineage documented
- [ ] Vault relationship lineage documented
- [ ] Bridge lineage documented

## Incident/change
- [ ] Incident/change reference recorded when applicable
- [ ] Root cause recorded for incidents
- [ ] Corrective action recorded
- [ ] Closure approval recorded

## Retention
- [ ] Approved retention policy identified
- [ ] Evidence repository identified
- [ ] Access to evidence restricted appropriately
