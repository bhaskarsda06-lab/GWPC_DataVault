# Phase 1 - GitHub Commands

Replace placeholders with your values.

```cmd
git init
git branch -M main
git config --global user.name "<YOUR NAME>"
git config --global user.email "<YOUR GITHUB EMAIL>"
git remote add origin https://github.com/<YOUR_USER>/GWPC_DataVault.git
git remote -v
git add .
git commit -m "Initial GWPC Data Vault Phase 1 foundation"
git push -u origin main
```
